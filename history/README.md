# PoC history

history/는 날짜순 작업 로그가 아니라 재현 가능한 기술 사례집이다. 디렉터리 이름은 YYYY-MM-topic 형식을 사용하고, 같은 주제의 후속 검증은 원본 결론을 덮어쓰지 말고 새 사례 또는 amendment로 남긴다.

## 사례 등록 기준

- 고객 환경에서 실제로 발생했거나 도입 판단에 직접 필요한 고난도 문제인가?
- 공식 문서만으로 확정하기 어렵고 실행 검증이 필요한가?
- 특정 EKS/Kubernetes/오픈소스 버전 또는 여러 계층의 상호작용이 핵심인가?
- 재현 결과가 다른 고객 문제에도 재사용될 가능성이 있는가?

하나라도 애매하면 일반 메모나 운영 문서에서 다루고 history에는 넣지 않는다.

## 필수 산출물

각 사례는 최소한 README.md, 독립 실행 가능한 Terraform root/state, evidence/, references.md를 포함한다. 증거가 없는 결론은 확정 판정으로 기록하지 않는다.

## 판정 상태

- 가능: 정의한 성공 조건을 모두 충족
- 조건부 가능: 특정 버전·설정·제약에서만 충족
- 불가능: 정의한 조건에서 실패가 재현됐고 근거가 확보됨
- 미확인: 증거 부족, 외부 차단 또는 검증 범위 밖

테스트하지 않은 내용을 불가능으로 확대 해석하지 않는다.
